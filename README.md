# 🎆 New Year Countdown 2027

A live countdown timer to 2027 — fully vibe-coded by AI.

## Features

- **Live countdown** — days, hours, minutes, seconds ticking down to Jan 1, 2027
- **Year progress** — shows how far through the current year (e.g. 34.2%)
- **Fireworks 🎇** — particle fireworks auto-launch when you're under 24 hours
- **Confetti 🎊** — bursts when the timer hits zero
- **Dark/Light mode 🌙☀️** — top-right toggle, respects your system preference
- **Share 📋** — copies the URL to your clipboard
- **Timezone** — auto-detects and shows your local timezone + UTC offset
- **Fully reactive** — no page refresh needed, everything updates live
- **Responsive** — works on desktop and mobile
